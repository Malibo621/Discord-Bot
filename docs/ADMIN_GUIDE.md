# دليل إدارة البوت

> هذا الدليل لمن يدير البوت داخل ديسكورد (مسؤول السيرفر). للمطوّر انظر [PROJECT_MAP.md](PROJECT_MAP.md).

## 1) كل شيء يبدأ من `/panel`

اكتب **`/panel`** (تظهر لك وحدك، وتغلق بعد 10 دقائق من الخمول). الصفحة الرئيسية تُظهر حالة السيرفر وأقسامًا مجمّعة حسب وظيفتها:

| المجموعة | القسم | ماذا تفعل فيه |
|---|---|---|
| 🎮 الفعاليات والاقتصاد | **الألعاب** | تفعيل كل لعبة، مددها، مكافآتها، إضافة كلمات وأسئلة مخصصة |
| | **النقاط والمكافآت** | اسم العملة، التحويلات، حماية الكسب، إضافة/خصم/تحديد رصيد عضو |
| | **المتجر** | إضافة منتجات ورتب، المخزون، الإخفاء، تسليم الطلبات أو استرجاعها |
| 🛡️ الحماية والإدارة | **الحماية والإدارة** | السبام، الروابط، منع التخريب، وعقوبات التحذيرات التلقائية |
| 🔧 السيرفر والبوت | **القنوات والسجلات** | رومات السجلات وروم الألعاب وإشعارات الشراء |
| | **الصوت والموسيقى** | الاتصال الدائم بروم صوتي (24/7) وزر لرتب التحكم بالموسيقى |
| | **الصلاحيات** | ربط فئات الأوامر (إدارة، اقتصاد، متجر، فعاليات، موسيقى…) برتب السيرفر |
| | **الأوامر والاختصارات** | تعطيل الأوامر، تعديل أوصافها، الاختصارات النصية (`!ban`) |

قسم «🔔 ما يحتاج انتباهك» في الرئيسية يعرض ما ينقصك فعلًا (روم سجل غير محدد، طلبات متجر معلّقة…).

### طريقة تعديل أي إعداد (نفس الخطوات في كل الأقسام)

1. اختر **قسمًا** من القائمة العلوية.
2. اختر **الإعداد** من القائمة الثانية. كل خيار فيه قيمته الحالية وشرح مختصر.
3. بحسب نوع الإعداد:
   - 🔘 **تفعيل/تعطيل**: يتبدّل فورًا.
   - 🔢 **رقم** أو 🔤 **نص**: تفتح نافذة بها المدى المسموح. اتركها فارغة للرجوع للقيمة الافتراضية.
   - #️⃣ **روم** أو 🎖️ **رتبة**: تظهر قائمة اختيار، مع زر «إلغاء التحديد».
4. يُحفظ فورًا ويبقى بعد إعادة التشغيل، وتصلك رسالة تأكيد بالقيمة الجديدة وشرحها، ويُسجَّل التعديل في روم سجل السيرفر.
5. زر **🏠 الرئيسية** يعيدك للصفحة الرئيسية، و**↩️ رجوع** يخرجك من شاشة الاختيار الحالية.

اضغط **📖 شرح الإعدادات** داخل أي قسم لترى صفحات تشرح كل إعداد: وظيفته، قيمته الحالية، مداه وقيمته الافتراضية، وكيف تغيّره.

## 2) الصلاحيات

- **المسؤولون (Administrator) ومالك السيرفر** يملكون كل شيء دائمًا.
- لغيرهم تُحدَّد الصلاحيات بـ **فئات** في `/panel ← الصلاحيات`: كل فئة تُربط برتب. بلا رتب تُستخدم صلاحية ديسكورد الافتراضية:

| الفئة | ماذا تتحكم به | الافتراضي |
|---|---|---|
| إدارة | تحذير/كتم/طرد/حظر/مسح | `moderate_members` |
| اقتصاد | إضافة/خصم النقاط | `manage_guild` |
| متجر | إدارة المنتجات والطلبات | `manage_guild` |
| فعاليات | بدء ألعاب بمكافآت مخصصة | `manage_events` |
| موسيقى | تخطي/إيقاف للجميع، حذف من الطابور | `move_members` |
| تجاوز الحماية | استثناء من السبام والروابط | `manage_messages` |

كل ضغطة زر أو إرسال نافذة تُفحص صلاحيتها **من الخادم** عند التنفيذ، فسحب رتبة من مسؤول أثناء فتح اللوحة يوقفه فورًا.

## 3) أوامر مفيدة خارج اللوحة

| الأمر | الفائدة |
|---|---|
| `/panel` | لوحة الإدارة الرئيسية |
| `/commands` | استعراض كل الأوامر وتعطيلها وتعديل أوصافها واختصاراتها |
| `/settings view` · `/settings set` | عرض الإعدادات أو تعديلها بالأمر (للمبرمجين والسكربتات؛ اللوحة أسهل) |
| `/shopadmin …` | إدارة المتجر بالأوامر، و`/shopadmin failures` لعمليات الشراء الفاشلة |
| `/warn` `/warnings` `/delwarn` `/clearwarns` | نظام التحذيرات |
| `/points …` | التحكم بنقاط الأعضاء |
| `/music panel` | إظهار لوحة الموسيقى في الروم الحالي |

## 4) لوحة الموسيقى

رسالة واحدة تتحدث في مكانها، بترتيب ثابت: **بطاقة الأغنية** (غلاف، عنوان، فنان، تقدّم) ← **أزرار التحكم** ← **الطابور**.

- الصف الأول: السابق · إيقاف مؤقت/استئناف (الأبرز) · تخطي · إيقاف.
- الصف الثاني: خفض الصوت · نسبة الصوت · رفع الصوت · تكرار · القائمة الكاملة.
- الطابور داخل اللوحة يعرض أول 5 أغانٍ قادمة؛ **القائمة الكاملة** تفتح رسالة مخفية بصفحات، ولأصحاب صلاحية «موسيقى» حذف أغنية أو مسح القائمة.
- الإيقاف المؤقت لأي مستمع في الروم الصوتي؛ بقية التحكم لصاحب الأغنية أو صاحب صلاحية «موسيقى» أو إن كان وحده مع البوت.

## 5) أخطاء شائعة

| المشكلة | الحل |
|---|---|
| لا أرى أمرًا جديدًا | أعد تشغيل البوت (يزامن الأوامر مع السيرفر عند التشغيل) |
| البوت لا يرسل في روم | امنحه صلاحيات العرض والإرسال والتضمين وإرفاق الملفات |
| لا يتصل بالروم الصوتي | امنحه العرض والاتصال والتحدث في ذلك الروم |
| الصور بلا خط عربي | ضع خطًا في `assets/fonts/` (انظر README قسم 12) |
