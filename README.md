# بوت السيرفر المتكامل

بوت ديسكورد بالعربي يجمع: الموسيقى، الألعاب والفعاليات، النقاط والاقتصاد والمتجر، الإدارة والحماية، والسجلات — وكلها مترابطة وتُحفظ في قاعدة بيانات (SQLite) فلا يضيع شيء عند إعادة التشغيل.

---

## 1) التشغيل

**المتطلبات:** Python 3.10 أو أحدث، و FFmpeg (للموسيقى). مكتبات رسم عجلة الروليت (Pillow وتشكيل العربي) تُثبَّت تلقائيًا من `requirements.txt`.

> على لينكس: إن ظهرت الأسماء على العجلة كأرقام فقط، ثبّت خطًا يدعم العربية (`sudo apt install fonts-dejavu-core`) أو ضع أي خط `.ttf` في `assets/font.ttf` أو حدد مساره في `BOT_FONT_PATH` داخل `.env`.

```bash
# تثبيت FFmpeg
# Windows:  winget install ffmpeg
# macOS:    brew install ffmpeg
# Linux:    sudo apt install ffmpeg

pip install -r requirements.txt
cp .env.example .env      # ثم ضع التوكن داخل الملف
python main.py
```

> ضع آيدي سيرفرك في `GUILD_ID` داخل `.env` لتظهر الأوامر فورًا. بدونه تظهر الأوامر لكل السيرفرات خلال ساعة تقريبًا.

## 2) إعداد البوت في Discord Developer Portal

1. أنشئ تطبيقًا من https://discord.com/developers/applications ← **Bot** ← انسخ التوكن.
2. فعّل في **Privileged Gateway Intents**:
   - ✅ Server Members Intent
   - ✅ Message Content Intent (ضروري للألعاب ومكافحة السبام)
3. من **OAuth2 → URL Generator** اختر `bot` و `applications.commands`، والصلاحيات:
   Manage Roles، Kick Members، Ban Members، Moderate Members، Manage Channels، Manage Messages، View Audit Log، Read Message History، Send Messages، Embed Links، Add Reactions، Connect، Speak.
4. **مهم:** بعد دخول البوت، اسحب رتبته في إعدادات السيرفر **فوق** الرتب التي سيبيعها في المتجر والرتب التي سيكتمها/يطردها.

## 3) أول إعداد داخل السيرفر (للمسؤول)

**الأسهل:** اكتب `/panel` لتفتح لوحة التحكم وتضبط كل شيء بالقوائم والأزرار (انظر القسم 5).
أو بالأوامر:

```
/settings channel  kind:السجل العام   channel:#logs
/settings channel  kind:سجل الإدارة   channel:#mod-logs
/settings channel  kind:سجل الاقتصاد  channel:#economy-logs
/settings channel  kind:روم الألعاب   channel:#games        (اختياري)

/permissions add  category:أوامر الإدارة   role:@Staff
/permissions add  category:بدء الفعاليات   role:@Events

/shopadmin add  name:VIP  price:2000  kind:رتبة  role:@VIP  duration_hours:720
/settings set   key:reward_quiz  value:30
/settings view
```

## 4) الأنظمة والأوامر

### 🪙 النقاط والاقتصاد
| الأمر | الوظيفة |
|---|---|
| `/balance [member]` | المحفظة: الرصيد، الترتيب، ألعاب فاز بها، كسب اليوم |

| `/points add / remove / set / reset` | تحكم الإدارة بالنقاط مع السبب، ويُسجَّل كل شيء |

### 🛒 المتجر
| الأمر | الوظيفة |
|---|---|
| `/shop` | عرض المنتجات |
| `/buy item` | الشراء — خصم تلقائي ومنح الرتبة فورًا |
| `/inventory` | المشتريات وحالتها ومدة انتهائها |
| `/shopadmin add / edit / remove` | إدارة المنتجات (السعر، الكمية، المدة، مرة لكل عضو، إخفاء) |
| `/shopadmin pending / deliver / refund` | متابعة طلبات المكافآت الخاصة، تسليمها، أو استرجاع النقاط |

نوعان من المنتجات: **رتبة** (تُمنح تلقائيًا، ويمكن جعلها مؤقتة وتُسحب عند انتهاء المدة) و**مكافأة خاصة** (يصل الطلب لروم سجل الاقتصاد لتسلّمه الإدارة).

### 🎮 الألعاب والفعاليات
| الأمر | اللعبة |
|---|---|
| `/game roulette` | عجلة روليت مرسومة بأسماء المشاركين تدور بأنيميشن وتتوقف على الفائز. نمط **إقصاء** اختياري: العجلة تختار كل جولة من يطرد منافسًا، والنهائي بدوران العجلة |
| `/game typing` | أسرع من يكتب الكلمة |
| `/game quiz` | سؤال معلومات عامة بأزرار، محاولة واحدة لكل عضو |
| `/game guess` | خمّن الرقم مع تلميحات ⬆️⬇️ |
| `/game scramble` | فكّك الكلمة المبعثرة |
| `/game math` | الحساب السريع |
| `/game list` | قائمة الألعاب ومكافآتها |
| `/game add-word` · `add-question` · `content` · `remove-content` | إضافة محتوى خاص بسيرفرك |
| `/game stop` | إيقاف لعبة قائمة |

كل لعبة يمكن تفعيلها/تعطيلها وتعديل مدتها ومكافأتها من `/panel`. الفائز في كل جولة يُصرف له مرة واحدة فقط حتى مع الضغط المتكرر.

**بطاقات الألعاب المصوّرة** (`bot/gamecards.py`): كل لعبة تُعرض كصورة مرسومة برمجيًا بشخصيتها الخاصة (شبكة للحساب، خطوط سرعة للكتابة، مربعات حروف للتفكيك، مقياس نطاق للتخمين، لوحة خيارات للأسئلة) وشاشة نتيجة بأفاتار الفائز.
- **الحركة:** شريط الوقت يفرغ داخل صورة GIF، وقصاصات ورق على شاشة الفوز، والروليت بعجلة تدور. ديسكورد لا يدعم انتقالات بين نسختين من الرسالة، لذلك الانتقال بين مراحل اللعبة يتم بتبديل صورة الرسالة نفسها.
- **دقة المؤقت:** شريط الـ GIF يبدأ عند تحميل الصورة عند كل عضو (قد يتأخر ثانية أو اثنتين)؛ المرجع الرسمي هو العدّاد النصي في الرسالة.
- **الإعدادات** (من `/panel` ← الألعاب): `عرض الألعاب كبطاقات مصوّرة` لإيقاف الصور والعودة للنص، و`تفعيل حركة المؤقت والقصاصات` لاستخدام صور ثابتة فقط (مناسب لمن يفضّل تقليل الحركة).
- **البديل التلقائي:** إن لم يملك البوت صلاحية «إرفاق الملفات» في الروم، أو فشل الرسم، تعمل اللعبة بالنص كما كانت.
- **الصوت:** غير مدعوم داخل رسائل ديسكورد (لا يمكن تشغيل صوت تلقائيًا عند الأعضاء)، ولم يُضف انضمام للرومات الصوتية دون طلب واضح.

منظّمو الفعاليات يقدرون يضيفون `reward:500` لأي لعبة لتصير **فعالية خاصة** بجائزة مخصصة (بحد أقصى يحدده المسؤول).

— التخطي والإيقاف لصاحب الأغنية أو لرتبة الموسيقى، ويخرج البوت تلقائيًا عند فراغ الروم.

### 🔨 الإدارة
`/warn` · `/warnings` · `/delwarn` · `/clearwarns` · `/mute` (مثال: `10m`، `2h`، `1d` أو `30د`، `2س`) · `/unmute` · `/kick` · `/ban` · `/unban` · `/clear` · `/lock` · `/unlock` · `/slowmode`
— كتم أو طرد تلقائي عند الوصول لعدد تحذيرات تحدده، ورسالة خاصة للعضو، وتسجيل كل إجراء.

### 🛡️ الحماية (تلقائية)
- **السبام:** رسائل سريعة أو مكررة ← حذف + كتم.
- **الروابط:** حذف أي رابط خارج القائمة المسموحة، ومنع دعوات السيرفرات؛ التكرار = تحذير تلقائي.
- **المنشن الجماعي:** حذف + كتم.
- **التخريب:** إذا حذف أحد الإداريين رومات/رتب أو حظر/طرد أعضاء بشكل جماعي ← تُسحب رتبه فورًا ويُنبَّه المالك.
- **الدخول الجماعي:** تنبيه في سجل الإدارة.
- الرتب في فئة **تجاوز الحماية** مستثناة.

### 📋 السجلات
حذف وتعديل الرسائل، دخول وخروج الأعضاء، تغيير الرتب والألقاب، إنشاء وحذف الرومات والرتب، الحظر وفكّه، الرومات الصوتية — بالإضافة لسجل الإدارة وسجل الاقتصاد.

## 5) الحماية من الاستغلال

| الحماية | كيف تعمل |
|---|---|
| عمليات ذرّية | كل خصم وتحويل وشراء يتم في معاملة واحدة؛ مستحيل يصير رصيد سالب أو شراء مزدوج حتى لو ضغط العضو عدة مرات |

| الحسابات الوهمية | الحسابات الجديدة أو حديثة الدخول لا تكسب ولا تحوّل (المدة قابلة للتعديل) |

| ألعاب الكتابة | الكلمة تُعرض بمحارف مخفية، فالنسخ واللصق لا يُحتسب، والإجابات الأسرع من البشر تُرفض |

| انتظار بين الألعاب | في نفس الروم، ولعبة واحدة فقط في كل روم |
| التحويلات | ضريبة، حد أدنى، حد يومي، وانتظار بين التحويلات |
| المتجر | لا يمكن بيع رتبة فيها صلاحيات إدارية، ومنع شراء نفس المنتج مرتين (اختياري) |

كل هذه القيم تُعدّل من `/settings set`.

## 6) إضافة لعبة جديدة مستقبلًا

1. أضف إعداداتها في `bot/settings_schema.py` (تظهر تلقائيًا في `/panel`):
   `Setting("reward_mygame", "مكافأة لعبتي", "int", 20, "مكافآت الألعاب", 0, 100000)`
   `Setting("game_mygame_enabled", "تفعيل لعبتي", "bool", True, "الألعاب")`
2. أضف تعريفها في `GAMES` داخل `cogs/games.py` (الاسم، الأيقونة، الوصف، طريقة اللعب).
3. اكتب الأمر بنفس نمط الألعاب الموجودة:
   ```python
   ctx = await self._prepare(interaction, "mygame", reward)
   if not ctx: return
   try:
       await self._send_card(interaction, ctx, self._card(ctx, s, "محتوى اللعبة", ends_at=ends))
       ...  # منطق اللعبة
       extra = await self._award(interaction.guild, winner, ctx)   # يُصرف مرة واحدة فقط
       await self._close(ctx, f"فاز {winner.mention}")
   finally:
       self._finish(ctx)
   ```
   وبهذا تحصل تلقائيًا على: المكافأة، الحد اليومي، فحص الأهلية، الانتظار، والسجل.

## 10) 🧩 لوحة الأوامر `/commands` والاختصارات النصية

`/commands` (للمسؤولين فقط، ومن `/panel` ← «الأوامر والاختصارات») لوحة مخفية لإدارة كل أوامر البوت:

| ما تفعله | الأثر |
|---|---|
| **استعراض** كل الأوامر مع وصفها وتصنيفها (عام/ألعاب/إداري) وصلاحيتها وخياراتها واختصاراتها، مع تصفية وبحث وصفحات | — |
| **تفعيل/تعطيل** أمر | فوري ويُحفظ. الأمر يبقى ظاهرًا في ديسكورد لكنه يرد «معطّل» (للأوامر الأصلية والاختصارات). `panel` و`commands` و`help` محمية |
| **تعديل وصف** أمر أو خيار (مع معاينة قبل الحفظ) | يُحفظ فورًا، ولا يراه الأعضاء في قائمة ديسكورد إلا بعد زر **تطبيق على ديسكورد** (مزامنة، بمهلة دقيقة) |
| **استعادة الافتراضي** (الوصف والخيارات والتفعيل) | ضغطتان للتأكيد |
| **الاختصارات النصية**: إضافة، إعادة تسمية، حذف، تغيير البادئة، تشغيل/إيقاف، واقتراحات جاهزة | فوري ومحلي |

### الاختصارات النصية
- لا يسمح ديسكورد بتشغيل أمر Slash بكتابة اسمه بلا `/`، لذلك الاختصار **أمر نصي يعالجه البوت**: اكتب البادئة ثم الاختصار، مثل `!ban @user السبب` أو `!رصيد @user`.
- الاختصار يُنفّذ **الأمر الأصلي نفسه** بنفس الفحوص (الصلاحيات، تعطيل الأمر، صلاحيات البوت)، فلا يمكن تجاوز الصلاحيات به. المنطق غير مكرر.
- البادئة مطلوبة دائمًا (الافتراضي `!`، قابلة للتغيير) كي لا تُشغَّل الأوامر من كلام عادي. تُنفَّذ الاختصارات فقط للأوامر القابلة لذلك؛ أوامر `/panel` و`/commands` و`/settings` و`/permissions` والموسيقى مستثناة.
- المدخلات بالترتيب نفسه لخيارات الأمر؛ آخر خيار نصي (كالسبب) يأخذ بقية السطر، والخيارات الاختيارية التي لا تناسب النص تُتخطّى (`!ban @user سبب طويل` تعمل دون كتابة `delete_days`).
- لا يمكن لاسم الاختصار أن يطابق اسم أمر آخر أو اختصارًا موجودًا (حتى لا يحدث لبس).

### قيود المنصة
- إخفاء الأوامر الإدارية عن غير المسؤولين في قائمة ديسكورد مطبّق على `/settings` و`/permissions` و`/commands` فقط. باقي الأوامر الإدارية (`/ban` و`/points`...) تعتمد على رتب يحددها المسؤول، وإخفاؤها بصلاحية ديسكورد الافتراضية قد يحجبها عن رتب مخوّلة؛ فالمنع فعلي من الخادم عند التنفيذ.
- أوصاف الأوامر عامة للبوت (وليست لكل سيرفر)، لأن ديسكورد يسجّل الأوامر على مستوى التطبيق/السيرفر الواحد؛ البوت مصمم لسيرفر واحد.
- تغيير **أسماء** أوامر Slash أو خياراتها غير مدعوم عمدًا (يكسر الاستخدام الحالي)؛ لتسمية بديلة استخدم اختصارًا نصيًا.

## 11) المتجر المرئي، الصور 16:9، «اسرع»، الاتصال الدائم، والموسيقى

### 🛒 `/shop` (للجميع، وللمخوّلين لوحة إدارة)
أمر واحد باسم `/shop` (ديسكورد لا يسمح بأمرين بنفس الاسم): يعرض **بطاقة متجر مرئية** (منتجات بصورها وأسعارها ومخزونها) مع قائمة اختيار منتج ← بطاقة تفاصيل ← زر شراء بتأكيد، وأزرار صفحات و«مقتنياتي».
لمن يملك صلاحية **المتجر** يظهر زر **⚙️ إدارة المتجر** (يُعاد فحص الصلاحية من الخادم عند الضغط) يفتح لوحة مخفية:
- **إضافة** مكافأة أو رتبة (اسم، سعر، وصف، رابط صورة https، كمية/مدة) • **تعديل** • **المخزون** • **إخفاء/إظهار** • **حذف** بتأكيد بضغطتين.
- الحذف «ناعم»: يختفي المنتج ولا يمكن شراؤه، لكن المشتريات والاستردادات السابقة تبقى سليمة (لا تُحذف بيانات أحد).
- صور المنتجات تُجلب بحماية (https فقط، رفض العناوين الداخلية، سقف 4MB، بلا تحويلات)، وفشل صورة يُظهر أيقونة بديلة ولا يعطّل المتجر.
- الأوامر القديمة `/buy` و`/shopadmin` باقية وتعمل بنفس المنطق (والإدارة صارت تدعم `image_url`).

### 🧩 لماذا كانت الأوامر تظهر مرتين؟
سُجّلت 32 أمرًا **عالميًا** (من أول تشغيل قبل ضبط `GUILD_ID`) ثم سُجّلت نسخة أخرى على **السيرفر** بعد ضبطه؛ ديسكورد يعرض النسختين معًا (تحققت من ذلك بقراءة الأوامر المسجّلة فعليًا).
الإصلاح: عند وجود `GUILD_ID` يحذف البوت **النسخ العالمية القديمة فقط** عند الإقلاع (لا يمسّ أوامر السيرفر ولا أي تعريف في الكود)، ويسجّل ذلك في الـ log. للإبقاء على الأوامر العالمية ضع `KEEP_GLOBAL_COMMANDS=1` في `.env`.
كما صار تشغيل نسختين من البوت ممنوعًا بقفل (`data/.bot.lock`) كي لا تتكرر الردود أو تتضارب جلسات الصوت.

### 🖼️ أحجام الصور
كل بطاقات الألعاب والمعلومات 16:9 بدقة **1280×720** (الروليت 960×540 والـ GIF بنفس النسبة)، بخطوط وعناصر أكبر. ديسكورد يعرض **المرفق المستقل** أكبر من صورة داخل Embed، لذلك الافتراضي مرفق مستقل. إن أردت الصورة داخل الإطار الملوّن فعّل «صورة اللعبة داخل الإطار» من `/panel` ← الألعاب (`game_image_in_embed`). حجم العرض النهائي يحدده تطبيق ديسكورد عند كل مستخدم، فجرّبه على جوالك وحاسوبك.

### ⚡ `-اسرع`
اكتب `-اسرع` (بالضبط) في أي روم فيبدأ تحدي سؤال عام بتصميم كبير، وأول من يكتب الإجابة الصحيحة يفوز بجائزة `reward_fast` مرة واحدة (تلميح في منتصف الوقت). كذلك `/game fast`. كلمة البدء قابلة للتغيير (`fast_trigger`، يجب أن تبدأ برمز). يتطلب **Message Content Intent** مفعّلًا في Developer Portal (نفس ما تحتاجه ألعاب الكتابة). يمكن تعطيله من `/panel` ← الألعاب أو `/commands`.

### 🎙️ الاتصال الدائم بروم صوتي (24/7)
حدّد الروم من `/panel` ← القنوات ← «الروم الصوتي للاتصال الدائم»، أو `/settings channel kind:الصوت الدائم`، أو ضع `VOICE_CHANNEL_ID=آيدي_الروم` في `.env`. يتصل البوت عند التشغيل، ويعيد الاتصال عند الانقطاع بفواصل متصاعدة (5ث ← 15ث ← 30ث ← 1د ← 2د ← 5د) ولا يدخل أي روم آخر، ويعود للمنزل إن نُقل. لا يحتاج تشغيل أغنية، ولا يغادر عند خلو الروم. الصلاحيات المطلوبة: رؤية الروم والاتصال والتحدث. مع الاتصال الدائم يجب أن يكون طالب الأغنية داخل ذلك الروم.
**الاستضافة:** البوت يعمل على جهاز التشغيل نفسه؛ إن أُطفئ الجهاز أو دخل السكون أو أُغلقت النافذة يتوقف الاتصال. للعمل 24/7 فعليًا شغّله على خادم دائم (VPS أو جهاز لا ينام). على ويندوز استخدم `run_forever.bat` ليعيد التشغيل تلقائيًا بعد أي انهيار (القفل يمنع النسخ المكررة).

### 🎵 `/play`
أُضيف أمر `/play` مباشرة (اختصار لـ `/music play`) — لم يكن موجودًا كأمر مستقل — ورسائل الخطأ صارت واضحة (محتوى غير متاح، يتطلب تسجيل دخول، شبكة، FFmpeg مفقود، انتهاء مهلة الاتصال) بدل الفشل الصامت، مع محاولة ثانية للأعطال العابرة، وبطاقة «يعمل الآن» مرئية بغلاف الأغنية.

### 📇 بطاقات المعلومات
`/balance` و`/leaderboard` و`/userinfo` والمتجر وبطاقة الأغنية بتصاميم إنفوجرافيك من بيانات النظام الحقيقية (بلا ذكاء اصطناعي، ~100ms للرسم). عند فشل الرسم أو تعطيل الإعداد `info_cards` تعود الردود النصية المعتادة.

### متغيرات البيئة (`.env`) الجديدة — كلها اختيارية
`VOICE_CHANNEL_ID` • `KEEP_GLOBAL_COMMANDS` • `BOT_FONT_PATH` (خط عربي بديل على لينكس).

## 12. الهوية البصرية والخطوط

كل الصور (بطاقات الألعاب، الرصيد، المتجر، الموسيقى، التحذيرات، الروليت) تمر عبر وحدة واحدة `bot/fonts.py`، ويظهر شعار السيرفر دائرةً في الزاوية العلوية اليمنى.

- **الخط:** لا نشحن ملفات خطوط (لأسباب الترخيص). البوت يبحث بالترتيب: `assets/fonts/` (أو المجلد في `BOT_FONT_DIR`) ثم خطوط النظام (Bahnschrift/Dubai على ويندوز).
- **للحصول على شكل DIN:** ضع ملفات الخط (`.ttf`/`.otf`) في `assets/fonts/`؛ الملفات التي يحوي اسمها `din` تتقدم على غيرها، والاسم الذي يحوي `bold` يُستخدم للعريض. خيارات مجانية مناسبة: D-DIN، Tajawal، IBM Plex Sans Arabic، Noto Sans Arabic (تحقق من ترخيص كل خط).
- **اللغات:** لكل حرف خط احتياطي تلقائي (لاتيني/أرقام ثم عربي)؛ الرموز غير المدعومة كالإيموجي تُحذف بدل أن تظهر مربعات.
- **لينكس/استضافة:** ضع خطوطًا في `assets/fonts/` لأن خطوط ويندوز غير موجودة هناك. المجلد مستبعد من git.
- إن لم يُوجد خط أو شعار، يستمر البوت بدونه (لا أعطال).

## 13. نظام التصميم الموحّد (Nova)

كل الصور تُبنى من `bot/canvas.py` (رموز الألوان `INK/INK2/INK3/SURFACE/GOLD…`، المسافات `M/GAP`، والمكوّنات:
`header`، `card`، `hero`، `chip`، `tile`، `progress`، `avatar`، `coin`، `game_frame`، `timer`). القوالب في
`bot/cards.py` (المحفظة، الملف، المتصدرون، المتجر، الموسيقى، التحذيرات) و`bot/gamecards.py` (الألعاب) و`bot/wheel.py` (الروليت).

- لغة موحّدة: صفحة فاتحة بنقاط نصف تدرجية، بطاقات بيضاء بظل ناعم، **بطاقة بطل كحلية واحدة** للعنصر الأهم، لون مميّز لكل نوع.
- الأرقام الضخمة لا تُقتطع أبدًا (تصغر ثم تُختصر «مليار/مليون»)، والأسماء الطويلة تصغر ثم تُقتطع بـ «…».
- صور الأمثلة قبل/بعد في `design_preview/`. لإعادة توليدها: شغّل القوالب ببيانات تجريبية (انظر اختبارات `tests/test_features.py`).
- للرجوع للتصميم السابق: `git checkout 281c4d1 -- bot/canvas.py bot/cards.py bot/gamecards.py bot/wheel.py`.
